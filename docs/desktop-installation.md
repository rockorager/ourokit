# Installing desktop integration

`tools/desktop/install.py` produces a desktop entry and, only when requested, a
D-Bus activation service. It can also install application and MIME icons and a
Shared MIME Info XML package. The input is JSON; the tool never evaluates Lua.

```json
{
  "id": "org.example.Notes",
  "name": "Notes",
  "comment": "Read and write notes",
  "ouroctl": "/usr/bin/ouroctl",
  "manifest": "/usr/share/example-notes/ouro.json",
  "dbus_activation": true,
  "icon": {"source": "notes.svg", "size": "scalable"},
  "mime_types": ["application/x-example-note"],
  "schemes": ["example-note"],
  "categories": ["Office"],
  "custom_mime_xml": "example-notes.xml",
  "mime_icons": {
    "application/x-example-note": {"source": "note-64.png", "size": "64x64"}
  }
}
```

`id`, `name`, and absolute installed paths `ouroctl` and `manifest` are
required. The ID must match the manifest and `ouro.app` declaration; the tool
does not evaluate the application to check this. Source paths are relative to
the metadata file. App icon names default
to the application ID; MIME icon names default to the conventional
`type-subtype`. SVG icons require `scalable`; PNG icons require `WIDTHxHEIGHT`.
`mime_types`, URI `schemes`, categories, icons, and custom MIME XML are optional.
The desktop entry advertises declared MIME types and schemes but this tool never
edits `mimeapps.list` or makes the application a default handler.
Declared handlers get `-- %U` in the desktop Exec line so fallback launches
receive file/URI arguments. Paths are quoted as arguments, not shell commands.
The executable path cannot contain `%` (GLib launcher lookup does not decode
literal percent escapes there); percent signs in manifest paths are supported.

Generate a tree for inspection or packaging:

```sh
python3 tools/desktop/install.py packaging/desktop.json --output build/desktop
python3 tools/desktop/install.py packaging/desktop.json \
  --prefix /usr --destdir "$pkgdir"
```

`DESTDIR` changes only the staging destination. Metadata paths must name their
final installed locations (for example `/usr/bin/ouroctl`, not a staging path).
For an explicit per-user install, the data directory is `XDG_DATA_HOME`, or
`~/.local/share` when unset:

```sh
python3 tools/desktop/install.py packaging/desktop-user.json --user
```

Use final per-user paths in that metadata. An explicitly set relative
`XDG_DATA_HOME` is rejected. Generated files follow `applications/`,
`dbus-1/services/`, `icons/hicolor/`, and `mime/packages/` conventions.

## Activation and caches

`DBusActivatable=true` and the `.service` file are emitted only when
`dbus_activation` is `true`. The Ourokit app **must** declare
`single_instance = true`: the service runs `ouroctl run MANIFEST
--dbus-activated`, while desktop `Exec` remains an ordinary `run` fallback.
Without the option, installation does not change Ourokit's multi-instance
default.

This installs integration metadata and the supplied icons/MIME XML, not the
application source bundle or Ourokit executable. Reinstallation replaces files
generated by the current metadata; it does not remove obsolete files from older
metadata. A packager must remove those explicitly, including an old `.service`
if disabling activation. No system files or caches are modified by generation
with `--output` or a disposable `--destdir`.

After installing, upgrading, or removing custom MIME XML, the packager or user
must run `update-mime-database DATADIR/mime`. Run
`update-desktop-database DATADIR/applications` when the desktop environment or
packaging policy requires its MIME-handler cache, and refresh the icon cache
when required by that environment (commonly `gtk-update-icon-cache
DATADIR/icons/hicolor`). These commands are deliberately not run by the tool:
they may be unavailable or inappropriate while staging a package.

The layout and escaping follow the freedesktop.org [Desktop Entry
Specification](https://specifications.freedesktop.org/desktop-entry-spec/latest/),
[Shared MIME-info Database](https://specifications.freedesktop.org/shared-mime-info/latest/),
and [XDG Base Directory Specification](https://specifications.freedesktop.org/basedir/latest/).
